## Status

> [!IMPORTANT]
> **Development has not started yet.** There is nothing to download. [T6-QoL](https://github.com/DavidHiFi/T6-QoL) is the current focus, and work on Black Ops III begins once that is finished.

## Mod manager

The [**Blutac Launcher**](https://github.com/DavidHiFi/Blutac-Launcher) already launches Black Ops III through the T7-CLL or [BOIII Community](https://gitlab.com/boiii-community/BOIII-Community) clients.

[Download it](https://github.com/DavidHiFi/Blutac-Launcher/releases/latest): setup or portable zip, Windows 10 or 11.

## Notes

> [!NOTE]
> **Black Ops III does not run on Plutonium.** This mod will install a different way from the rest of the series.
